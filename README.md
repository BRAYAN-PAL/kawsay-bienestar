# Kawsay Bienestar

Sistema de citas, autogestión, trazabilidad y evaluación de riesgos operativos para un centro de bienestar de Los Olivos, Lima, Perú.

El código está en [serena/](serena/). Consulta la [guía de ejecución y despliegue](serena/README.md).

Backend Node.js, base de datos privada en Supabase PostgreSQL, alojamiento en Render y asistente de reservas con Ollama local. La marca, dirección provisional, equipos y tratamientos son configurables; no se presentan como datos de una empresa real.
